# Level #10

Processes, Users, Permissions

---

> [!NOTE]
> Don't forget to run `check.sh` to get your key.

---

## Level Description

1. Please create bash script `sleeper.sh`.

2. Add a user `agent` with a home directory.

3. Using absolute mode give user `agent` read and write permission to the script.

4. Write a singular sleep command ***in the background*** for no more than 10 secs inside `sleeper.sh` script.

5. Using symbolic mode give yourself execution permission to the script and run it.

6. Find its PID and use it to kill it with the suitable flag.
