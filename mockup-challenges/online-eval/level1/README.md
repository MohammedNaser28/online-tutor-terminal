# Level Description

1. Extract the `archive` file and check its contents.

2. List ***all*** of its contents and look for any hidden layers.

3. Recursively look inside the inner directories.

4. Map out the words of hidden objects to create the password consisting of `3` numbers in each file or directory's name.

5. Pass them as parameters in this order `file-dir-file` to validate your solution ***without any spaces or delimiters in between***. 

### Example submission shape: `./check.sh 790`
