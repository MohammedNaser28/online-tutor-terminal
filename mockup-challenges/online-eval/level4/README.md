# Level #4

Users and Permissions

---

> [!NOTE]
> Don't forget to run `check.sh` to get your key.

---

## Level Description

1. Create a new user `penguin`.

2. Create a group `pengroup` using `addgroup` (this sandbox uses busybox).

3. Switch user `penguin`'s primary group to `pengroup`.

4. Delete user `penguin`'s old primary group using `delgroup`.
