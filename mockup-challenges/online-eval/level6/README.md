Compression & Archiving, Text processing

---

> [!NOTE]

## Level Description

You have an archived and compressed file.

Your mission is to:

1. Uncompress the archived file.
2. List the contents of the archived file.
3. Extract only these files from the archive:

   * `Random.txt`
   * `Debian.txt`
   * `Fedora.txt`
4. Get every punctuation character from the extracted files.
5. Count the punctuation characters in each extracted file.
6. Determine which file contains the maximum number of punctuation characters.
7. Run `check.sh` with the full name of the file with max characters (filename and extension) as an argument to the script.

***Don't forget to give `check.sh` the right permissions!***
