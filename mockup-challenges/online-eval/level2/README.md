## Level Description

1. Create a directory `link_lab` with a base file `original.txt`  to link against.

2. Generate one of each link type pointing to your original file.

3. View the file details and **inode** numbers using the `ls` command.

4. Append new text to the soft link and check the contents of all three files.

5. Delete the original file and try to read both links.
