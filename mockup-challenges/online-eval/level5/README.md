# Level #5

Searching for Files

## Check Guidelines
- Run `check.sh` with your result as a parameter to get the key, something like `check.sh file`

## Level Description
- Search in "files" directory for a file's name of ***exactly*** four charecters ending in `.py` extension.
- Pass just the file name **without the full path or extension** as a parameter to "check.sh" file, *if file path is `files/test/zero.py` then check with `check.sh zero`*
